# **App Name**: AscendEd

## Core Features:

- Authentication: User authentication and authorization to secure access to student data.
- Student Management: Add, edit, and manage student profiles, including personal information and assigned goals.
- Goal Template Management: Create, store, and retrieve goal templates for various educational domains (e.g., articulation, language comprehension).
- SMART Goal Generation: AI tool that suggests SMART (Specific, Measurable, Achievable, Relevant, Time-bound) goals based on user-defined prompts.
- Session Data Entry: Record and track student progress for each goal through session data entry, with customizable input fields based on goal type.
- Progress Analysis: Generate visual reports and charts to analyze student progress and identify trends.
- Activity Suggestions: AI tool that suggests activities appropriate for various learning goals. The tool factors in session history and student progress.

## Style Guidelines:

- Primary color: HSL(210, 67%, 46%) which converts to #3874F0, offering a vibrant yet trustworthy feel, suitable for educational applications.
- Background color: HSL(210, 20%, 25%) which converts to #333F4C, provides a professional, unobtrusive backdrop.
- Accent color: HSL(180, 55%, 50%) which converts to #4DD0E1, providing contrast to highlight interactive elements.
- Body and headline font: 'Inter', a sans-serif font known for its readability and modern aesthetic, ensuring clear content presentation.
- Consistent use of Lucide React icons for a unified and intuitive user experience.
- Mobile-first responsive design with a maximum content width of 6xl, ensuring optimal viewing across devices.
- Subtle transitions and animations to provide feedback and guide users through the application.
